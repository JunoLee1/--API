# 레이더 차트 강점/약점 판정은 절대 임계값 AND 상대 비교 복합 기준을 쓴다

단일 기준 대신 절대 임계값(A)과 팀 내 포지션 그룹 상대 비교(B)를 복합 적용한다.

## Considered Options

- **절대 임계값만 (A)**: 구현 단순. 리그 수준 무관 — 약팀 선수가 강점으로 잘못 표시되는 문제.
- **상대 비교만 (B)**: 팀 맥락 반영. 팀 인원이 적으면 표본 부족으로 의미 없는 태그 발생.
- **복합 기준 (채택)**: A의 최소 품질 보장 + B의 팀 맥락 반영.

## Decision

```
강점 = 해당 축 점수 ≥ 70 AND 팀 내 동일 포지션 그룹 상위 25%
약점 = 해당 축 점수 ≤ 40 OR 팀 내 동일 포지션 그룹 하위 25%
```

- **강점은 AND**: 절대 품질 보장. 소규모 팀에서 낮은 절대값 선수가 "상위 25%"로 강점 태그 받는 것을 방지.
- **약점은 OR**: 더 민감하게 감지. 절대적으로 낮거나 상대적으로 뒤처지면 코치에게 경고.
- **표본 부족 (동일 포지션 그룹 3명 미만)**: 상대 비교 비활성화, 절대 임계값만 적용.

## Consequences

레이더 차트 축은 포지션 그룹별로 독립 정의 (공격수·미드필더·수비수·골키퍼 각 6축). 포지션 그룹은 기존 CONTEXT.md 코칭 역할 매핑 그룹과 동일하게 사용한다. 축 정의는 CONTEXT.md `PlayerMatchStats` 섹션 참조.
