### 의료비 결재 (MedicalExpense)

MEDICAL → MEDICAL_DIRECTOR(1차) → ADMIN(최종) 3단계 워크플로우.

**상태머신:** `DRAFT → SUBMITTED → LEADER_APPROVED → APPROVED / REJECTED`  
REJECTED 상태에서 원 신청자 재상신 가능. 재상신 시 `rejectionReason` 초기화.

#### API (BE)

| 파일 | 내용 |
|------|------|
| `apps/api/src/medical-expense/medical-expense.repo.ts` | CRUD + submit·leaderApprove·leaderReject·approve·reject 5개 상태전이 |
| `apps/api/src/medical-expense/medical-expense.service.ts` | 권한별 list 필터. 알림 발송: submit→MEDICAL_DIRECTOR 전원, leaderApprove→ADMIN 전원, reject/approve→신청자 개인 |
| `apps/api/src/medical-expense/medical-expense.controller.ts` | isMedical·isMedicalDirector·isAdmin 가드 분리 |
| `apps/api/src/medical-expense/medical-expense.routes.ts` | multer diskStorage(`uploads/medical-expenses/`, 20MB). 9개 라우트 |
| `apps/api/src/apiRouter.ts` | `/medical-expenses` 라우터 등록 |

#### UI (FE)

| 파일 | 내용 |
|------|------|
