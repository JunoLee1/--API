# 배포 수정 요약 — 2026-08-06

## 해결된 문제

### 1. API 500 에러 (PR #153)
**문제:** `/api/departments`, `/api/meal-expenses`, `/api/staff-records`, `/api/sponsorships` 500 에러  
**원인:** 마이그레이션 `20260802163055`의 `ALTER TYPE "FrontOfficeRole" ADD VALUE 'FACILITY_MANAGER'`가 비멱등성 실행으로 P3009 무한 루프  
**수정:** Dockerfile에서 P3009 처리를 `--rolled-back` → `--applied`로 변경  
**결과:** 4개 엔드포인트 401(인증 필요)로 정상화 ✓

### 2. 사이드바 메뉴 스크롤 (PR #154)
**문제:** 데스크탑 사이드바 메뉴가 스크롤 안 됨  
**원인:** `<nav>` 엘리먼트에 `overflow-y-auto` 미적용  
**수정:** AppShell.tsx nav에 `overflow-y-auto` 추가, 팀 컨텍스트 스위처 중복 렌더링 제거  
**결과:** 메뉴 스크롤 정상 작동 ✓

### 3. repair-db.js 에러 체인 (PR #155)
**문제:** `staffSql` 실행 전 `repairSql2` 실패로 계정 미생성  
**원인:** `.then()` 체인에서 중간 실패 시 이후 쿼리 중단  
**수정:** async/await + 독립 `.catch()`로 각 쿼리가 독립 실행  
**결과:** superAdminSql, staffSql 독립 실행 보장 ✓

### 4. HR_STAFF/ASSET_STAFF/FINANCE_STAFF enum 누락 (PR #156)
**문제:** `staffSql`이 존재하지 않는 enum 값으로 INSERT 실패  
**수정:** repairSql2에 `ALTER TYPE "FrontOfficeRole" ADD VALUE IF NOT EXISTS 'HR_STAFF'` 등 추가  
**결과:** _STAFF 계정 생성 가능 ✓

### 5. FINANCE_MANAGER/ASSET_MANAGER/HR_MANAGER/FACILITY_MANAGER enum 누락 (PR #157)
**문제:** _MANAGER 계정 생성 시 500 에러  
**원인:** `repairSql2` 멀티-스테이트먼트 배치에서 `ALTER TYPE ADD VALUE`가 PostgreSQL 암묵적 트랜잭션 내에서 실패  
**수정:**
- ALTER TYPE 문들을 `enumAdditions` 배열로 분리, 각각 별도 `client.query()` 호출
- 새 마이그레이션 `20260806001000_fix_frontoffice_manager_enum_values` 추가
- `staffSql`에 `asset.manager@club.com`, `finance.manager@club.com` 추가  
**결과:** 모든 _MANAGER 계정 로그인 성공 ✓
