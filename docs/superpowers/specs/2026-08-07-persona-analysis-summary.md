## 1. Mark — 고령 영국인 IT 약자

> "I haven't the foggiest idea where to start."

**핵심 고통점:**

- **진입점 혼란**: 메뉴가 9개 섹션(Players·Matches·Training·Finance·HR·Reports 등)으로 나뉘어 있어, "계약 갱신 확인"을 위해 Player Management와 HR 중 어디를 눌러야 할지 모름
- **용어 장벽**: xG, xA, aerial duel success rate 등 전문 지표에 설명이 전혀 없음
- **권한 표시 불명확**: 버튼이 왜 회색인지 알 수 없음 — 권한 때문인지, 데이터가 없는 건지 구분 불가
- **테이블 가로 스크롤**: 선수 통계 테이블이 너무 넓어, 읽다가 어느 행인지 잃어버림
- **실수 복구 불가**: "UNACTIVE"를 잘못 클릭했다가 되돌리지 못함 (명확한 Undo 없음)
- **날짜 형식 불분명**: DD/MM/YYYY vs MM/DD/YYYY 안내 없음
- **도움말 전무**: 버튼 설명·매뉴얼·툴팁 없음
- **KPI 카드 단위 없음**: "87"이 퍼센트인지, 건수인지, 천 단위인지 알 수 없음
- **로그인 오류 메시지 불친절**: 기술적인 빨간 글씨만 표시

**요약**: 복잡도를 전혀 줄여주지 않는 인터페이스. IT 약자를 위한 단순화 경로(역할별 가이드 화면, 툴팁, 도움말) 필요.

## 2. Jack — 영국인 재무팀장 (5년차)

> "Creating an audit trail that stops halfway is not acceptable."

**핵심 고통점:**

- **단일 P&L 뷰 없음**: 티켓 수입(SalesRecord), 스폰서십(SponsorshipPayment), 급여(PayrollRun), 운영비(OperatingExpense)가 각각 분산돼 있고, 통합 손익계산서 엔드포인트 없음
- **원장 취소·환불 불가**: 티켓 판매 시 LedgerEntry가 자동 생성되지만, 환불·취소 시 역분개 처리가 없어 수익 과대 계상
- **발생주의 미지원**: 시즌권은 현금 수령 시 전체 계상되어야 하나, 경기별 수익인식(이연수익) 지원 없음
- **예산 카테고리 과도하게 단순**: TRAVEL/EQUIPMENT/SCOUTING/YOUTH만 존재 — 코스트센터별 분리 불가
- **감사 문서 첨부 없음**: 지출 증빙 서류를 거래 항목에 연결하는 필드 없음
- **부가세 코드 없음**: 거래별 세금 코드 부재 → VAT 신고 시 수동 작업
- **예산 집행률 단일 수치**: 카테고리·부서·기간별 세분화 없이 전체 퍼센트만 제공
- **현금흐름 지표 없음**: 수납율과 미납율은 있으나 실제 현금 유입 타이밍 지표 없음
- **결산 마감 잠금 없음**: 이전 기간에 소급 전기 가능 → 기보고 수치 변경 위험
- **보고서 내보내기 없음**: PDF·Excel 정형 보고서 자동 생성 기능 없음

**요약**: 운영 기록 도구로는 작동하나, 감사·회계 기준을 충족하는 재무 시스템 수준에는 미달. 발생주의·세금·역분개·보고서 자동화 필요.

## 3. Steve — 한국인 HR 담당자 (5년차, 꼼꼼)

> "선수들과 유소년 아이들을 제대로 챙기고 싶은데 시스템이 그걸 막는 순간들이 있어서 답답합니다."

**핵심 고통점:**

- **출결 정정 선수 미통보**: correctAttendance 감사 로그에는 남지만, 선수 본인에게 알림 없음 → 페널티 카운트 변경 이유를 직접 연락해서 설명해야 함
- **페널티 발동 ≠ 실질 징계**: "페널티가 부여될 수 있습니다" 알림만 발송, 실제 징계 프로세스 연결 없음
- **출결 미입력 세션 대시보드 없음**: nullOnly 필터로 직접 찾아야 함 — 마감 전날 허겁지겁 확인
- **채용 퍼널 전환율·평균 채용일 없음**: 경영진 보고용 HR 지표를 별도 엑셀로 수동 작성
- **지원자 거절 취소 불가**: 실수로 거절 처리한 지원자를 DB 직접 수정 없이는 복구 불가
- **인터뷰 일정 변경 시 지원자 미통보**: updateInterview 로직에 알림 없음
- **온보딩 OTP 전달 방법 없음**: 이메일 발송 연동 없어 카톡·문자로 수동 전달
- **공지 미열람자 개별 추적 불가**: 읽음률 % 수치만 있고 미열람자 목록·개별 재발송 없음
- **스태프 인사 기록 없음**: 선수 계약 관리는 탄탄하지만, 프런트·코칭 스태프 고용계약·연차·근속 관리 없음
- **헤드카운트 통제 없음**: 채용 공고에 포지션당 채용 인원·예산 한도 필드 없음

**요약**: 선수 관련 워크플로우는 잘 설계됐으나, 채용 운영·스태프 인사·공지 관리 세부 기능에서 "사람을 끝까지 챙기지 못하는" 구조적 공백.

## 4. Rooney — 영국인 FC Seoul 구단주 (한국어 가능, 현실주의자)

> "I'm paying for the whole thing and I can't tell if this club is making money, building asset value, or slowly bleeding out."

**핵심 고통점:**

- **오너 전용 역할 없음**: ADMIN·GM 어느 쪽도 투자자/오너에게 필요한 뷰 미제공 — 구단주가 ADMIN으로 로그인해야 하는 상황
- **통합 P&L 없음**: 수입·지출이 분산돼 있고, 시즌 전체 영업이익을 한 화면에서 확인 불가
- **스쿼드 자산 가치 집계 없음**: 선수별 시장 가치는 있으나, 팀 전체 자산 가치·전년 대비 변동 없음
- **스폰서십 ROI 없음**: 계약 지불 현황은 있으나 계약 만료 알림·갱신 가능성 플래그 없음
- **이적 재정 총정산 없음**: 시즌 순이적비(수입 - 지출) 집계 없음
- **티켓 수입 ↔ 경기 성적 연동 없음**: 승/패 후 티켓 수입 변화 상관관계 분석 불가
- **임금 총액 대시보드 없음**: 월별 전체 급여 합계, 수익 대비 임금 비율 없음
- **다년도 트렌드 없음**: 모든 보고서가 현 시즌·현 월 기준 스냅샷, 3개년 추이 비교 불가
- **아카데미 ROI 없음**: 아카데미 운영 비용 대비 1군 선발 인원·시장 가치 추적 없음
- **부상 재정 비용 없음**: 의료비는 기록되나, "부상으로 뛰지 못한 선수에게 지불한 임금 총액" 지표 없음

**요약**: 운영 도구로는 우수하나, 경영 의사결정 도구로는 근본적으로 설계 방향이 다름. 오너/이사회용 Executive Dashboard가 필요.

## 5. 박지성 — FC Seoul 감독 (IT 약자)

> "로그인하면 오늘 훈련 출결, 부상 선수 명단, 다음 경기 일정, 이 세 가지만 바로 보이면 솔직히 충분합니다."

**핵심 고통점:**

- **감독 대시보드에 필요한 정보 없음**: 오늘 훈련 결석자·복귀 임박 부상자·다음 경기까지 D-Day가 한눈에 안 보임
- **메뉴 복잡도**: 재무·계약·시설 메뉴까지 전부 노출됨 — 감독에게 불필요한 항목이 2/3 이상
- **부상 선수 목록 조회 불편**: 선수 한 명씩 이름 선택해야 현황 확인 가능 — 전체 부상자 목록 뷰 없음
- **출결 컬럼 과잉**: 7개 컬럼에 설명 없음 — "이 선수 잘 나오나 못 나오나"만 알면 되는데 너무 복잡
- **선수 통계 테이블 22개 컬럼**: 감독이 필요한 기본 지표(득점·어시스트·출전시간)가 분석관용 xG 등과 섞여 있음
- **스쿼드 플래너 저장 없음**: 포메이션 배치 후 페이지 이탈 시 초기화 — 저장 버튼 없음
- **전술 분석 보고서 읽기 전용 뷰 없음**: 클릭하면 수정 폼이 열림 — 분석관이 써둔 보고서를 읽는 기능 없음
- **영어 상태값 그대로 노출**: DRAFT·CONFIRMED·PRE_MATCH 등 일부만 번역되어 혼재
- **대시보드 2개**: 메인 대시보드 + 코치 대시보드가 별도 존재 — 어느 것을 봐야 하는지 혼란

**요약**: 시스템이 감독 역할을 위해 실질적으로 설계되지 않음. 역할 기반 극단적 단순화와 "오늘의 핵심 3가지" 즉시 뷰 필요.

## 6. 이연주 — 한국인 K리그 HR팀장 (5년차, 빡센 성격)

> "숫자 보여주는 것보다 그 숫자로 내가 즉시 행동할 수 있어야 합니다. 그게 진짜 ERP예요."

**핵심 고통점:**

- **KPI 드릴다운 없음**: 공지열람률 85% → "나머지 15%가 누구인지" 바로 볼 수 없음. 숫자는 장식
- **출결 수정 감사 로그 없음**: 코치가 결석을 지각으로 수정했을 때 이력 없음 → 이의신청 대응 불가
- **이의신청 워크플로우 없음**: 페널티 부과 전 소명 절차가 시스템 밖(이메일·카톡) — 이중 관리
- **계약 만료 자동 알림 없음**: 30/60/90일 전 알림 없음 → 스프레드시트 수동 관리
- **훈련 데이터 ↔ 인사 평가 연동 없음**: 보고서 복붙 = 오류의 시작
- **외국인 선수 비자·노동허가 만료 추적 없음**: K리그 규정상 60일 전부터 챙겨야 함
- **연봉 인상 시뮬레이션 없음**: 재계약 협상 시 팀 전체 인건비 영향 엑셀로 따로 계산
- **공지 수신 대상 필터링 없음**: 포지션별·계약 유형별 선택 발송 불가 → 전체 발송만 가능
- **모바일 최적화 불명확**: 원정 중 코치 출결 입력 → 데이터 품질 저하
- **유소년 ↔ 1군 이력 연동 없음**: 아카데미 출신 선수가 1군 등록 시 이력 자동 연결 없음

**요약**: 데이터는 쌓이는데 행동으로 연결되지 않는 시스템. 드릴다운·자동 알림·이의신청 워크플로우가 최우선.

- **장비 유닛 테이블에 '사용 선수' 표시 오류 가능성**: `UNIT_SELECT`(`equipment.repo.ts:14-17`)에 `assignedTo` 관계가 포함 안 됨 — `EquipmentPage.tsx:526`의 `unit.assignedTo?.playerName`이 항상 `'—'`으로 표시될 수 있음. 어떤 선수가 어떤 장비를 쓰는지 못 보면 ¡imposible! 관리가 되겠어요?
- **반납 버튼 텍스트 오류**: `EquipmentPage.tsx:360` — ISSUED 상태의 반납 버튼이 `rejectButton` 키 사용. "거절"이 반납 버튼에 떠있는 거, amigo, 이건 선수가 헷갈릴 수밖에 없어요
- **시설 존 중 '라커룸' 없음**: `FacilityZone`이 GROUND·MECHANICAL·STRUCTURAL·SAFETY·SANITATION·OPERATIONS — 라커룸(LOCKER_ROOM), 의무실(MEDICAL_ROOM), 샤워실(SHOWER_ROOM)이 별도 구분 없음. ¡Dios mío! 선수들이 제일 많이 쓰는 공간인데!
- **점검 실패 → 유지보수 자동 생성 없음**: ISSUE_FOUND 결과를 입력해도 MaintenanceRequest가 자동 생성 안 됨. Pedro 같은 베테랑은 수동으로라도 하지만, 신입 직원이라면 점검 기록만 올리고 유지보수는 잊어버릴 거예요
- **장비 대여 반납 시 상태 자동 복구 없음**: `returnLoan` 완료 시 해당 `EquipmentUnit.status`가 `IN_USE → AVAILABLE`로 자동 전환되지 않음 — 수동으로 상태 변경해야 함. 레알에서 이런 거 빠뜨렸다간 난리 나요

**요약**: ¡Mira amigo! 장비·시설 모듈 골격은 있는데, 30년 경력자 눈에는 위생 추적, 정기 점검 일정, 시설 존 세분화가 모두 빠져 있어요. 선수들이 불편해할 부분이 한두 개가 아닙니다. 가장 급한 건 장비 유닛 selet 누락 버그와 반납 버튼 텍스트 오류예요.
