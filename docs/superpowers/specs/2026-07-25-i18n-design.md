# i18n (다국어 지원) Design

## Goal

한국어로 고정된 Football ERP 앱을 한국어(ko) / 영어(en) 양쪽에서 사용 가능하게 만든다. 같은 서버 인스턴스에서 사용자별로 언어를 독립적으로 선택할 수 있다.

## Architecture

```
┌─────────────────────────────────────────────────────┐
│  Frontend (React)                                    │
│  react-i18next                                      │
│  src/locales/en/*.json  src/locales/ko/*.json       │
│  useTranslation('match') → t('goals')               │
└───────────────────┬─────────────────────────────────┘
                    │ PATCH /users/me/language
                    │ { language: 'en' | 'ko' }
┌───────────────────▼─────────────────────────────────┐
│  API (Hono)                                          │
│  User.language: 'ko' | 'en'  (Prisma 필드 추가)     │
│  src/i18n/messages/ko.ts                            │
│  src/i18n/messages/en.ts                            │
│  getMessages(locale) → message object               │
│  → 푸시 알림 발송 시 수신자 locale 조회 후 메시지 선택  │
└─────────────────────────────────────────────────────┘
```

## Tech Stack

- **Frontend:** `i18next`, `react-i18next` (번역 파일은 번들에 포함, HTTP backend 불필요)
- **API:** 자체 메시지 맵 (외부 라이브러리 없음)
- **DB:** `User.language String @default("ko")`

---

## 1. Frontend Translation File Structure

네임스페이스를 기능 도메인별로 분리한다.

```
src/locales/
├── ko/
│   ├── common.json       # 공통 버튼, 상태값, 포지션명, 에러 메시지
│   ├── match.json        # 경기, 선수 스탯, 슈팅 이벤트
│   ├── player.json       # 선수 프로필, 레이더 축 이름
│   ├── training.json     # 훈련, 출결
│   ├── squad.json        # 스쿼드, 라인업
│   ├── medical.json      # 부상, 의무 비용
│   ├── contract.json     # 계약, 이적
│   ├── youth.json        # 유소년 등록, 콜업
│   ├── report.json       # 리포트, 전술
│   └── admin.json        # 관리자, 장비, 대시보드
└── en/
    └── (동일 구조)
```

**키 스타일:** `common.save`, `match.goals`, `player.radar.stability` 형태의 dot-notation 계층 사용.

**사용 패턴:**
```tsx
// 컴포넌트에서
const { t } = useTranslation('match')
<th>{t('goals')}</th>   // ko: "골" / en: "Goals"
```

**레이더 `안정성` 키:** API가 반환하는 레이더 점수 키를 `stability`로 변경(영어로 통일). 프론트에서 `t('player.radar.stability')` → "안정성" / "Stability" 로 렌더링.

## 2. Language Preference Storage & Switching

**DB 스키마:**
```prisma
model User {
  // 기존 필드들...
  language  String  @default("ko")  // "ko" | "en"
}
```

**언어 전환 흐름:**
1. 사용자가 헤더의 `KO / EN` 토글 클릭
2. `i18next.changeLanguage(lang)` 즉시 호출 (낙관적 UI 반영)
3. `PATCH /users/me/language { language: 'en' }` API 호출
4. 실패 시 이전 언어로 rollback

**초기 로드:**
- 로그인 응답에 `language` 필드 포함
- `i18next.changeLanguage(user.language)` 호출
- 로그아웃 시 `'ko'`로 리셋

**신규 API 엔드포인트:**
- `PATCH /users/me/language` — body: `{ language: 'ko' | 'en' }`, 인증 필요

```typescript
  },
  youth: {
    rejected: (name: string) => `${name}'s academy registration has been rejected.`,
    enrolled: (name: string) => `${name} has officially joined the academy.`,
  },

    shortage: (positions: string) => `There are positions with insufficient available players — ${positions}.`,
  },

```

**헬퍼:**
```typescript
// src/i18n/t.ts
import { ko } from './messages/ko'
import { en } from './messages/en'

const messages = { ko, en } as const

export function getMessages(locale: string) {
  return messages[locale as 'ko' | 'en'] ?? messages.ko
}
```

**사용 패턴:**
```typescript
// notification.service.ts
const recipient = await this.prisma.user.findUnique({ where: { id }, select: { language: true } })
const m = getMessages(recipient?.language ?? 'ko')
await push({ title: m.injury.occurred(playerName) })
```

**범위 제한:** 알림 제목/본문만 번역. API 에러코드(`KEY_PASS_REQUIRES_PASSES_ATTEMPTED` 등)는 영어 코드 유지 — 프론트에서 `t('errors.KEY_PASS_REQUIRES_PASSES_ATTEMPTED')` 로 번역.

## 4. Radar Key Fix

`radar.service.ts`에서 `안정성` 키를 `stability`로 변경한다. 이 키는 API 응답 JSON에 포함되어 프론트 차트 렌더링에 사용되므로, 영어 식별자로 통일해야 한다.

```typescript
// Before
{ 안정성: stability }

// After
{ stability: stabilityScore }
```

프론트 레이더 차트 컴포넌트에서 각 축 key → 번역 문자열 매핑:
```typescript
const { t } = useTranslation('player')
const axisLabel = (key: string) => t(`radar.${key}`, key)
// t('radar.stability') → "안정성" / "Stability"
```

## Out of Scope

- 3개 이상 언어 지원 (현재는 ko/en 2개)
- 날짜/숫자 포맷 로케일 변환 (기존 포맷 유지)
- API 에러코드 번역 (프론트에서 처리)
- 이메일 알림 번역 (현재 이메일 알림 없음)
