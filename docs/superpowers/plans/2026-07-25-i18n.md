# i18n (ko/en) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add ko/en language support — per-user preference stored in DB, react-i18next on frontend, message factories for API push notifications.

**Architecture:** `User.language` field in DB drives everything. Frontend uses react-i18next with 10 namespace JSON files. API notifications use a `getMessages(locale)` factory. Language toggle in AppShell header calls `PATCH /users/me/language`.

**Tech Stack:** `i18next`, `react-i18next` (frontend); plain TypeScript message maps (API); Prisma schema migration via `db push`.

**Spec:** `docs/superpowers/specs/2026-07-25-i18n-design.md`

- [ ] **Step 4: Add controller method**

In `apps/api/src/auth/auth.controller.ts`, add after the `me` method:

```typescript
updateLanguage = async (req: Request, res: Response, next: NextFunction) => {
  try {
    const { id } = this.getAuthenticatedUser(req);
    const { language } = req.body;
    if (language !== 'ko' && language !== 'en') throw new AppError(400, 'INVALID_LANGUAGE');
    await this.repo.updateLanguage(id, language);
    res.status(200).json({ ok: true });
  } catch (err) {
    next(err);
  }
};
```

async createForUser(
  userId: number,
  type: string,
  getMsg: (locale: string) => { title: string; body: string },
  entityId?: number,
) {
  const user = await this.prisma.user.findUnique({ where: { id: userId }, select: { language: true } });

  return this.prisma.notification.create({ data: { userId, type, title, body, entityId } as any });

```typescript
createForStaff(
  type: string,
  getMsg: (locale: string) => { title: string; body: string },
  entityId?: number,
) {
  return this.prisma.$transaction(async (tx) => {
    const users = await tx.user.findMany({
      where: { role: { in: ['ADMIN', 'FRONT_OFFICE'] } },
      select: { id: true, language: true },
    });
    await tx.notification.createMany({
      data: users.map((u) => {
        const { title, body } = getMsg(u.language ?? 'ko');
        return { userId: u.id, type, title, body, entityId };
      }) as any,
    });
  });
}

import i18n from '@/i18n'
import { authApi } from '@/services/auth.service'
import { useState } from 'react'

export function useLanguage(initialLanguage: 'ko' | 'en') {
  const [language, setLanguage] = useState<'ko' | 'en'>(initialLanguage)

  const changeLanguage = async (lang: 'ko' | 'en') => {
    const prev = language
    setLanguage(lang)
    await i18n.changeLanguage(lang)
    try {
      await authApi.updateLanguage(lang)
    } catch {
      setLanguage(prev)
      await i18n.changeLanguage(prev)
    }
  }

  return { language, changeLanguage }
}
```
