1.  Prisma create 타입 추론 오류
    문제 발생
    prisma.user.create() 에서 아래와 같이 작성했을 때 타입 에러 발생
    data: {
    countryId: 1,
    phoneNumber: {
    create: {
    iv: "...",
    encrypted: "..."
    }
    }
    }

        에러 : phoneNumber is not assignable to undefined

    원인 분석

        1. FK 입력 방식

            Prisma 타입은 크게 두개로 나눠지는 유니온 구조 이다.
            " UserCreateInput | UserUncheckedCreateInput "

            countryId 처럼 직접 입력을 하면 TypeScript가 UserUncheckedCreateInput 타입을 추론한다.
            즉 DB를 직접조회하기 위해 만든 타입으로 객체필드를 제한하기에 휴대폰 번호 타입을 추론을 제한 한다.

            => Prisma 타입 추론 꼬임

    문제 해결

        1. FK 입력 방식 통일

            FK Scaler 방식 대신에 relation 방식을 써서 prisma 타입 통일함

6.  트랜잭션

        다수 유저 정보 수정시엔, 중간에 실패한다면 롤백하여서 일관성 유지

13. 
    문제: cannot read 'disconnect'

    원인:

    - prisma가 초기 상태에서 undefined
    - getPrisma() 호출 전에 $disconnect 실행

    Prisma 6.x vs 7.x 차이:

    - 6.x: PrismaClient 여러 개 생성해도 비교적 문제 안 드러남
    - 7.x: connection 관리 엄격 + adapter 구조 → 문제 바로 발생

    핵심:

    - PrismaClient는 싱글톤으로 관리해야 함
    - 여러 번 생성하면 connection 문제 발생

    해결:

    - prisma.ts에서 getPrisma() 사용
    - 테스트에서도 동일 인스턴스 사용 (의존성 주입)
